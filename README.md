
# Object-Oriented Programming Using C++

This repository contains C++ programs implemented as part of the course **Object-Oriented Programming Using C++ (25EECE421)**, covering concepts from Chapters 1–4.

## Topics Covered

### Chapter 1: Fundamental Concepts of OOP
- Introduction to OOP
- Programming Basics and Data Types
- Arrays and Strings
- Functions and Parameter Passing Techniques

### Chapter 2: Classes and Objects
- Classes, Objects and Member Functions
- Encapsulation and Data Hiding
- Constructors and Destructors
- Scope Resolution Operator
- Static Data Members and Inline Functions
- Friend Functions and Friend Classes
- Nested Classes
- Passing Objects as Arguments

### Chapter 3: Inheritance
- Types of Inheritance
- Base and Derived Classes
- Access Specifiers
- Constructors and Destructors in Inheritance
- Constructor Initialization Lists
- Virtual Base Classes

### Chapter 4: Polymorphism
- Function Overloading and Overriding
- Virtual and Pure Virtual Functions
- Abstract Classes
- Reference Variables
- Static Functions
- `this` Pointer
- Operator Overloading

## Language & Tools
- **Language:** C++
- **Compiler:** GCC / G++
